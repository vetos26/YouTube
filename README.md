# НЕ СЛОЖНО — лендинг YouTube-канала

Адаптивный одностраничный сайт на чистом HTML, CSS и JavaScript. Включает главную секцию, карточки и фильтрацию выпусков, рассказ о ведущем, список тем и ссылки на подписку.

## Запуск

Откройте `index.html` в браузере или запустите любой локальный статический сервер из этой папки, например:

```bash
python3 -m http.server 8000
```

## Настройка под канал

Замените название, описания, тексты выпусков и ссылки `@neslozhno` в `index.html` на данные своего канала. Фильтры тем и сетка карточек находятся там же; стили — в `styles.css`, поведение фильтров и мобильной навигации — в `script.js`.
