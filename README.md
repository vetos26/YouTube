# НЕ СЛОЖНО — лендинг YouTube-канала

Адаптивный одностраничный лендинг для русскоязычного образовательного YouTube-канала. Концепция сайта — **«НЕ СЛОЖНО»**: ведущий Алекс простым языком рассказывает о технологиях, мышлении и науке в повседневной жизни.

## Что создано

- **Главная секция** с описанием канала, основным призывом посмотреть видео и визуальной иллюстрацией выпуска.
- **Каталог выпусков** из шести карточек: у каждой есть тема, заголовок, описание, длительность и ссылка на YouTube-поиск по теме.
- **Фильтры по темам**: технологии, мышление и повседневная наука.
- **Блок о ведущем**, список тематических направлений и секция подписки.
- **Адаптивная навигация** для мобильных экранов.
- Темная визуальная тема с яркими лаймовыми акцентами; обложки карточек собраны из CSS-графики — отдельные изображения не требуются.

Сайт реализован на чистых HTML, CSS и JavaScript, без сборщика и сторонних библиотек.

## Запуск локально

Можно открыть `index.html` в браузере или запустить встроенный статический сервер Python:

```bash
python3 -m http.server 8000
```

После запуска откройте <http://localhost:8000>.

## Файлы проекта

- `index.html` — разметка и тексты секций.
- `styles.css` — оформление, CSS-обложки и адаптивные стили.
- `script.js` — фильтрация видео и мобильное меню.

## Настройка под настоящий канал

Сейчас **«НЕ СЛОЖНО»**, ведущий и выпуски — демонстрационный контент. Перед публикацией подставьте реальные название и описание канала, ссылки, данные ведущего, ролики и просмотры. Ссылки на канал используют примерный адрес `@neslozhno`, а ссылки карточек ведут на поиск YouTube по указанной теме.

Основные тексты и адреса находятся в `index.html`. Для новых категорий обновите значения `data-category` у карточек и кнопок фильтра. Внешний вид редактируется в `styles.css`, поведение фильтров — в `script.js`.

## Публикация на GitHub Pages

Для размещения статического сайта в корне этого репозитория в настройках репозитория выберите **Settings → Pages → Deploy from a branch**, затем ветку `main` и каталог `/(root)`. После сохранения GitHub Pages опубликует `index.html` и связанные с ним файлы.
